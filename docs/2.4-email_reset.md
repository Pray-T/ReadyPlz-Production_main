## 2.4 이메일 비밀번호 재설정 기능
사용자가 비밀번호를 분실했을 때, 이메일로 **일회성 재설정 토큰 링크**를 발송하는 기능을 구현했습니다. 메일 발송은 비동기로 처리하여 사용자 응답 지연을 방지합니다.

**설계 의도**
- SMTP 587 포트(STARTTLS)를 사용하여 암호화된 메일 전송
- 메일 발송은 외부 I/O로 시간이 소요 → 비동기 처리로 사용자 응답 시간과 분리
- UUID 기반 일회성 토큰 + 만료 시간(1시간)으로 보안 확보

**비동기 처리 구조** <br>
ThreadPoolTaskExecutor 설정: <br>
Core Pool Size: 2 → 기본 상주 스레드 Max Pool Size: 5 → 최대 동시 처리 스레드 Queue Capacity: 100 → 대기열 크기 Thread Prefix: "mail-async-"

**처리 흐름**: <br>
사용자 요청 (POST /members/reset-request) → MemberService: UUID 토큰 생성 + DB 저장 (만료: 1시간) → EmailService.sendResetMail() ← @Async("mailTaskExecutor") → 즉시 응답 반환 (메일은 백그라운드에서 발송)

**비밀번호 재설정 전체 흐름** : <br>
① 사용자: 이메일 입력 → POST /members/reset-request ② 서버: UUID 토큰 생성 → Member 엔티티에 resetToken + resetTokenExpiry 저장 ③ 서버: @Async로 SMTP 메일 발송 (HTML 본문, 재설정 링크 포함) ④ 사용자: 이메일 링크 클릭 → GET /members/reset-password?token=xxx ⑤ 서버: 토큰 유효성 검증 (존재 여부 + 만료 시간 확인) ⑥ 사용자: 새 비밀번호 입력 → POST /members/reset-password ⑦ 서버: BCrypt 암호화 후 저장, 사용된 토큰 즉시 삭제 (일회성 보장)


**기술적 특징**
- `MimeMessageHelper`로 HTML 형식 이메일 발송 (사용자 친화적 UI)
- `@Async` + 전용 `ThreadPoolTaskExecutor`로 메인 스레드 지연 방지
- 토큰 사용 후 즉시 null 처리 → 재사용 불가 (일회성)
