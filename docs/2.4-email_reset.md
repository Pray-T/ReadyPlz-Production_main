## 2.4 이메일 비밀번호 재설정 기능
사용자가 비밀번호를 분실했을 때, 이메일로 **일회성 재설정 토큰 링크**를 발송하는 기능을 구현했습니다. 메일 발송은 비동기로 처리하여 사용자 응답 지연을 방지합니다.

**설계 의도**
- 로컬: `application.properties` 기준 `localhost:1025`(인증·STARTTLS 없음, MailHog 등 캡처용). 운영 발송 시 SMTP 587 + STARTTLS
- 메일 발송은 외부 I/O로 시간이 소요 → 비동기 처리로 사용자 응답 시간과 분리
- UUID 기반 일회성 토큰 + 만료 시간(1시간)으로 보안 확보
- **토큰이 DB에 커밋된 뒤(afterCommit)에만 메일을 발송** → 커밋 전 발송으로 사용자가 즉시 링크를 클릭했을 때 토큰이 조회되지 않는 문제를 방지

**비동기 처리 구조** <br>
ThreadPoolTaskExecutor 설정: <br>
Core Pool Size: 2 → 기본 상주 스레드 Max Pool Size: 5 → 최대 동시 처리 스레드 Queue Capacity: 100 → 대기열 크기 Thread Prefix: "mail-async-" <br>
사용하는 EC2 인스턴스가 2CPU(t3.micro)이기에 스레드 풀 사이즈를 서버의 스펙에 맞게 조절했습니다. 

**처리 흐름**: <br>
사용자 요청 (POST /members/reset-request) → MemberService: UUID 토큰 생성 + DB 저장 (만료: 1시간) → 트랜잭션 커밋(afterCommit) → EmailService.sendResetMail() ← @Async("mailTaskExecutor") → 메일은 백그라운드에서 발송

**비밀번호 재설정 전체 흐름** : <br>
① 사용자: 이메일 입력 → POST /members/reset-request ② 서버: UUID 토큰 생성 → Member 엔티티에 resetToken + resetTokenExpiry 저장 ③ 서버: 트랜잭션 커밋 후(afterCommit) @Async로 SMTP 메일 발송 (HTML 본문, 재설정 링크 포함) ④ 사용자: 이메일 링크 클릭 → GET /members/reset-password?token=xxx ⑤ 서버: 토큰 유효성 검증 (존재 여부 + 만료 시간 확인) ⑥ 사용자: 새 비밀번호 입력 → POST /members/reset-password ⑦ 서버: BCrypt 암호화 후 저장, 사용된 토큰 즉시 삭제 (일회성 보장)


**기술적 특징**
- `MimeMessageHelper`로 HTML 형식 이메일 발송 (사용자 친화적 UI)
- `@Async` + 전용 `ThreadPoolTaskExecutor`로 메인 스레드 지연 방지
- `TransactionSynchronization.afterCommit`으로 DB 커밋 성공 후에만 메일 발송 (커밋 전 발송 방지)
- 토큰 사용 후 즉시 null 처리 → 재사용 불가 (일회성)
